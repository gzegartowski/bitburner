# Bitburner Project

This project contains scripts for Bitburner, an idle/incremental game where you write Javascript code to automate tasks.

## Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository_url>
    ```
    (Replace `<repository_url>` with the actual URL of this repository)

2.  **Install Bitburner:**
    If you haven't already, download and install Bitburner from [https://danielyxie.github.io/bitburner/](https://danielyxie.github.io/bitburner/).

3.  **Configure Script Root:**
    - In Bitburner, go to the "Options" menu.
    - Find the "Script Root" setting.
    - Set the "Script Root" to the root directory of this cloned project.
    - **Important:** The VSCode settings in this project (`.vscode/settings.json`) are already configured to use the root directory as the script root (`"bitburner.scriptRoot": "."`).

## Running Scripts

Once Bitburner is configured to use this project's root directory, your scripts should appear in the game. You can run them from the game's terminal or through other scripts.
